Tentang saya

Saya Fajri Al Zikra, mahasiswa Program Studi D-IV Elektronika di Politeknik Negeri Padang yang saat ini menempuh semester 6. Saya memiliki ketertarikan mendalam pada dunia sistem tertanam (embedded systems), Internet of Things, serta perancangan rangkaian elektronika analog dan digital.

Sebagai mahasiswa kelas 3A DIV EC, saya aktif mengikuti praktikum laboratorium, mengerjakan proyek berbasis mikrokontroler, serta mempelajari pemrograman tingkat rendah untuk hardware. Saya percaya bahwa elektronika adalah fondasi dari hampir semua teknologi modern.

Tujuan saya setelah lulus adalah berkarier di industri otomasi, manufaktur elektronik, atau mengembangkan produk IoT yang berdampak nyata bagi masyarakat.

Proyek elektronika yang dikerjakan

01 — Proyek Unggulan

Sistem Monitoring Suhu & Kelembaban Berbasis IoT

Merancang sistem pemantauan lingkungan real-time menggunakan ESP32 dan sensor DHT22. Data dikirim via protokol MQTT ke dashboard berbasis web yang dapat diakses dari mana saja. Dilengkapi notifikasi otomatis saat nilai melebihi ambang batas.

ESP32 DHT22 MQTT IoT C++

02

Robot Line Follower Adaptif

Membangun robot otonom yang mengikuti garis menggunakan sensor inframerah array dan algoritma PID untuk koreksi lintasan yang halus dan responsif. Diprogram menggunakan Arduino Nano.

Arduino Algoritma PID Robotika
03

Power Supply Variable Terregulasi

Merancang catu daya variabel 1.25V–30V / 3A menggunakan IC LM317 dengan indikator digital tegangan dan arus berbasis ADC mikrokontroler AVR. Lengkap dengan proteksi arus lebih.

Analog AVR PCB Design
04

Smart Door Lock RFID

Sistem kunci pintu otomatis berbasis RFID RC522 dan STM32. Mendukung multi-user, pencatatan log akses, dan kontrol via keypad untuk PIN backup. Diintegrasikan dengan relay dan solenoid lock.

STM32 RFID C (HAL)
